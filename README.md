# Aprendiendo Java (Transición desde C++)

Repositorio que documenta mi evolución aprendiendo Java, abarcando desde fundamentos de consola hasta programación orientada a objetos e interfaces gráficas (`JOptionPane`).

## 🎯 Objetivo

Adaptar la lógica de programación aprendida en C++ a la sintaxis y características de Java, estructurando el código de manera modular y profesional.

## 📂 Contenido del Proyecto

* `ejercicios_java/` - Fundamentos, tipos de datos primitivos, manejo de strings y arreglos (Arrays).
* `Sistema_ecomerce/` - Ejercicios orientados a objetos (OOP), encapsulamiento y gestión de entidades.
* `Ventanas_Emergentes/` - Aplicaciones interactivas basadas en GUI con `javax.swing.JOptionPane`.
